# **Data Structures in C — Programs & Implementations**

This repository contains a well-curated collection of fundamental **Data Structure** and **Algorithm** programs implemented in **C**.
Each program is written with clarity, focusing on core logic, clean structure, and easy learning—ideal for students, beginners, and anyone brushing up on DS fundamentals.

---

## 📌 **Overview**

This repo covers:

* Core **Linear & Non-Linear Data Structures**
* Essential **Sorting Algorithms**
* Classic **Disk Scheduling Algorithms**
* Polynomial & Sparse Matrix operations
* Dynamic memory usage with C allocation functions

All programs include **insertion**, **deletion**, **traversal**, or **operation-specific logic** depending on the topic.

---

## 🗂️ **Contents**

### **1. Linked Lists**

* **Singly Linked List**
  Implementation with insertion, deletion, search, and traversal.
* **Stack using Linked List**
  Demonstrates stack operations using dynamic memory.

---

### **2. Stacks & Queues**

* **Basic Stack (Array-based)**
  Push, pop, peek, and display functions.
* **Basic Queue (Array-based)**
  FIFO operations using front & rear pointers.
* **Circular Queue**
  Efficient array-based queue using circular indexing.
* **Double Ended Queue (Deque)**
  Insert/delete at both ends.
* **Priority Queue**
  Queue arrangement based on assigned priority.

---

### **3. Trees**

* **Binary Tree**
  Node creation, insertion, and basic tree traversals (inorder, preorder, postorder).

---

### **4. Sorting Algorithms**

* **Insertion Sort**
  Step-by-step shifting and inserting logic.
* **Selection Sort**
  Finds minimum element repeatedly and places it in position.
* **Merge Sort**
  Divide-and-conquer algorithm with efficient merging.
* **Quick Sort**
  Partitioning and recursive sorting for high-performance results.

---

### **5. Polynomial Operations**

* **Polynomial Addition**
  Uses linked lists to add two polynomials efficiently.
* **Polynomial Multiplication**
  Term-wise multiplication and combining like terms.

---

### **6. Sparse Matrix**

* **Sparse Matrix Addition**
  Optimized representation of non-zero elements and matrix addition.

---

### **7. Disk Scheduling Algorithms**

* **C-SCAN (Circular SCAN)**
  Circular traversal to reduce seek time.
* **SCAN (Elevator Algorithm)**
  Moves in one direction, reverses at ends, and services requests efficiently.

---

### **8. Memory Management**

* **Dynamic Memory Allocation**
  Examples using `malloc`, `calloc`, `realloc`, and `free`.

---

### **9. C Structure Program**

* **Structure of a Student**
  Demonstrates use of `struct` for grouping and managing student-related data.

---
